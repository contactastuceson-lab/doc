## S'inscrire

1. Ouvrez la page de l'événement
2. Cliquez **S'inscrire**
3. Payez en crédits si l'événement est premium
4. Recevez votre billet avec QR code

## Le jour J

Présentez votre QR code pour le **check-in**. Vous recevez aussi un rappel automatique.

## Annuler

Annulation possible jusqu'à 24h avant. Les crédits sont remboursés selon la politique de l'organisateur.
