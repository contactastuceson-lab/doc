eza organise des événements en ligne, hybrides ou en présentiel. Voici comment vous inscrire, récupérer votre billet et même vous faire rembourser en crédits si besoin.

## S'inscrire à un événement

L'inscription se fait en deux gestes depuis la page de l'événement. Si l'événement est payant, vos crédits Eza sont débités.

<Steps>
</Steps>

<Tip>
  **Place limitée.** Certains événements ont un nombre de places limité. Inscrivez-vous tôt : une fois la capacité atteinte, l'inscription se ferme.
</Tip>

## Mon billet & le check-in

Chaque inscription génère un billet avec un code. Sur place, le scan du code valide votre entrée.

- Votre billet est dans « Mes événements » (Espace utilisateur).
- Il contient un code unique (ex : EZA-AB12CD34).
- Sur place, présentez le code à un organisateur pour le check-in.
- Les événements en ligne vous envoient un lien de connexion.

## Annuler & se faire rembourser

Vous ne pouvez plus venir ? Vous pouvez demander l'annulation. Si elle est approuvée, vos crédits vous sont rendus.

</Steps>

<Note>
  **Besoin d'aide ?** Pour une annulation urgente ou un problème de billet, ouvrez un ticket de support : Nexus IA peut traiter le remboursement en crédits automatiquement.
</Note>
