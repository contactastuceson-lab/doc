eza vous informe par trois canaux : dans l'app, par notification push sur votre téléphone, et par email. Voici comment réguler ce que vous recevez.

## Régler mes préférences

Chaque type d'événement (likes, messages, annonces, badges) peut être activé ou désactivé individuellement. Vous ne recevez que ce qui vous intéresse.

<Steps>
</Steps>

<Tip>
  **Push sur votre téléphone.** Pour recevoir les notifications sur votre téléphone, autorisez les notifications quand eza vous le demande, puis installez l'app pour un rendu natif.
</Tip>

## Les trois canaux

eza utilise trois façons de vous prévenir, selon le contexte.

| Canal | Détail |
| --- | --- |
| Dans l'app | La cloche en haut, visible quand vous naviguez sur eza. |
| Push | Sur votre téléphone, même quand l'app est fermée. |
| Email | Récapitulatifs et annonces importantes par email. |
