Votre profil est votre identité publique sur eza. Il affiche vos publications, vos badges, vos affiliations et vos statistiques. La page personnelle `/profile` réunit tous vos paramètres.

## Profil personnel (`/profile`)

Les paramètres sont organisés en sections :

| Section | Contenu |
| --- | --- |
| Compte | Nom, email, avatar, bio, username. |
| Préférences | Thème, langue, mode compact. |
| Notifications | Push, email, in-app (9 réglages). |
| Sécurité & confidentialité | 2FA, sessions actives, RGPD, suppression de compte. |
| Affiliations | Organisations auxquelles vous êtes rattaché. |
| Facturation | Abonnements et factures. |
| Suivi de certifications | Statut de vos demandes. |
| Username | Changer votre @username. |
| Danger zone | Suppression définitive du compte. |

## Profil public (`/@username`)

Accessible via `/profile/:username` ou `/@username`, visible par tout le monde même sans connexion (comme sur TikTok ou Instagram).

- **En-tête** : avatar, nom, @username, vérifications, badges, statistiques (abonnés, abonnements, publications).
- **Publications** de l'utilisateur, épinglées d'abord.
- **Bouton suivre / message** pour interagir.
- **Affiliations** publiques visibles sous forme de chips (logo d'organisation).

<Tip>
  **Un profil complet rassure.** Une photo claire, une bio précise, un site web et des badges donnent confiance. Un profil complet est plus facile à trouver et plus crédible.
</Tip>

## Le @username

Votre @username est unique et vous identifie partout : mentions (@pseudo) et URL publique (`eza.group/@pseudo`).

<Warning>
  **Choisi pour la vie.** Après une suppression de compte, l'ancien @username est gardé en réserve pendant 30 jours (entité `DeletedUsername`) pour empêcher qu'un nouveau compte n'usurpe votre identité.
</Warning>

## Préférences

Vous personnalisez votre profil dans les paramètres :

- **Thème** : automatique, clair, ou sombre.
- **Langue** : fr, en, es, de.
- **Mode compact** : réduit paddings et tailles.
- **Statut en ligne** : afficher ou masquer votre présence.

Vos préférences sont enregistrées (`UserPreferences`) et vous suivent sur tous vos appareils. Un composant `PreferencesApplier` les applique automatiquement au chargement.

## Vérifications et badges

Les vérifications et badges sont affichés sur votre profil, vos publications, vos stories et vos Spaces.

| Badge | Signification |
| --- | --- |
| Vérifié | Identité vérifiée. |
| Pro | Statut professionnel confirmé. |
| Certifié | Certification eza obtenue. |
| Officiel | Compte officiel (équipe eza ou organisation). |
| Fondateur | Badge historique fondateur. |
| Pilote | Certification pilote. |
| VIP | Statut VIP. |
| Partenaire | Partenaire officiel. |

Le clic sur une vérification ouvre une modale d'affiliation ou navigue vers le profil.
