## L'entité `ModuleStatus`

| Champ | Description |
| --- | --- |
| `name` | Clé du module |
| `status` | `operational`, `degraded`, `maintenance`, `outage` |
| `message` | Message affiché |
| `updated_at` | Dernière maj |
| `incident_started_at` | Début incident |
