## Entité `Partner`

| Champ | Description |
| --- | --- |
| `name` | Nom du partenaire |
| `logo_url` | Logo affiché |
| `website` | Lien externe |
| `description` | Présentation |
| `category` | Type de partenariat |
| `is_featured` | Mis en avant |

<Note>
  **Vision d'ensemble.** L'écosystème EZA vise à devenir un ensemble cohérent de services professionnels et communautaires connectés par une identité utilisateur unique.
</Note>
