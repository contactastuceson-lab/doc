## Comprendre les statuts

| État | Signification |
| --- | --- |
| Disponible | Utilisable pour un achat ou une action |
| Gelé | Réservé pour un événement, ticket, ou audit en cours |
| Débité | Sortie effectuée |
| Crédité | Entrée validée |
