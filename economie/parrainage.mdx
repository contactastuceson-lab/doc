Le parrainage récompense l'apport de nouveaux membres. Vous partagez votre code (votre @username), vos invités rejoignent eza, et vous gagnez des crédits à chaque étape.

## Mon code de parrainage

Votre code de parrainage est votre @username. Vous le partagez librement.

</Steps>

<Tip>
  **Partagez largement.** Chaque inscription validée vous rapporte des crédits. Utilisez vos réseaux sociaux, vos messageries, ou votre communauté.
</Tip>

## Les jalons

Plus vous parrainez, plus vous débloquez des récompenses bonus.

- Crédit initial à la première inscription d'un filleul.
- Récompenses bonus à chaque jalon (5e, 10e, 25e, 50e filleul).
- Les récompenses se cumulent : inscription \+ chaque jalon atteint.
- Suivez votre progression vers le prochain jalon depuis la page Parrainage.

## L'entité `Referral`

Chaque parrainage crée une entité `Referral` :

- Parrain (`referrer_id`).
- Filleul (`referred_id`).
- Statut (`pending`, `validated`, `revoked`).
- Récompenses attribuées (`rewards`).

<Note>
  **Suivez vos gains.** La page Parrainage affiche votre code, la liste de vos filleuls, vos gains cumulés et votre progression.
</Note>

## Jouer loyalement

Les tentatives de fraude (multi-comptes, robots d'inscription) sont détectées automatiquement.

<Warning>
  **Pas de triche.** Chaque parrainage est vérifié. La fraude (multi-comptes, bots) entraîne l'annulation des récompenses (`revoked`) et peut bloquer votre compte. Parrainez de vraies personnes.
</Warning>
