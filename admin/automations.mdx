## L'entité `AutomationLog`

| Champ | Description |
| --- | --- |
| `job_name` | Nom de la fonction |
| `category` | posts, credits, notifications, moderation, billing... |
| `status` | `success`, `partial`, `error`, `skipped` |
| `run_at` | Heure d'exécution |
| `duration_ms` | Temps d'exécution |
| `items_processed` | Nombre d'items traités |
| `error_message` | En cas d'échec |

## Catégories principales

| Catégorie | Exemples |
| --- | --- |
| **posts** | `publishScheduledPosts`, `expireStories` |
| **credits** | `awardDailyLogin`, `processCreditsMonthlyReset` |
| **notifications** | `sendDigest`, `notifyEventReminders` |
| **moderation** | `moderateReportedContent`, `runModerationSweep` |
| **billing** | `processDailyAdBudgets`, `renewSubscriptions` |
| **support** | `escalateOldTickets`, `recoverAbandonedCarts` |
| **cleanup** | `expireUsernameGrace`, `pruneOldSessions` |
