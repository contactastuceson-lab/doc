## Fonctions admin utilisateurs

| Fonction | Rôle |
| --- | --- |
| `adminGetUsers` | Liste avec filtres |
| `adminGetUsersByRole` | Filtre par rôle précis |
| `adminUpdateUser` | Modif rôle, statut, perks, verified |
| `adminSetUserRole` | Changement de rôle atomique |
| `adminResetUserProfile` | Réinitialisation profil |
| `adminExpireUsername` | Libérer un username |
| `adminAssignBadge` | Attribuer un badge manuel |
| `sendUserAdminAction` | Notif email de la sanction |
