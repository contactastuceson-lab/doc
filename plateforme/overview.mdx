## Pages publiques

Accessibles sans compte :

| Route | Contenu |
| --- | --- |
| `/` | Fil d'actualité \+ sidebars |
| `/blog` | Articles publiés |
| `/discover` | Découverte d'utilisateurs |
| `/portfolio` | Galerie de projets |
| `/forum` | Discussions du forum |
| `/enor` | Biographie fondateur |
| `/ecosysteme` | Écosystème EZA Group |
| `/business` | Espace business |
| `/@username` | Profil public |
| `/donation` | Faire un don |

<Tip>
  **Installez eza sur votre téléphone.** Depuis le navigateur → menu → « Ajouter à l'écran d'accueil ». Vous obtenez une icône et une app plein écran.
</Tip>
