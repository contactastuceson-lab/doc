## Rôles hiérarchiques

12 rôles définissent la hiérarchie sur la plateforme (champ `role` de l'entité `User`).

| Rôle | Description |
| --- | --- |
| `owner` | PDG propriétaire exclusif, pouvoirs illimités |
| `pdg_adjoint` | PDG-Adjoint, pouvoirs équivalents |
| `admin` | Administrateur système |
| `conseil_admin` | Conseil d'administration |
| `directeur` | Directeur de département |
| `responsable` | Responsable de service |
| `collaborateur_interne` | Collaborateur interne (staff) |
| `event_manager` | Gestionnaire d'événements |
| `pilote` | Pilote drone certifié |
| `collaborateur` | Collaborateur externe |
| `vip` | Utilisateur VIP |
| `user` | Utilisateur standard (défaut) |

## Statuts de compte

| Statut | Effet |
| --- | --- |
| `active` | Compte pleinement opérationnel |
| `suspended` | Suspendu temporairement (délai fixé) |
| `banned` | Banni définitivement, données conservées |
| `restricted` | Restreint (certaines actions bloquées) |

<Note>
  **Gel bancaire séparé.** Un compte peut avoir `bank_frozen: true` (portefeuille gelé) sans être banni. Motif conservé dans `bank_freeze_reason` avec date `bank_frozen_at`.
</Note>

## FAQ générale

<AccordionGroup>
  <Accordion title="eza est-il gratuit ?">
    Oui, toutes les fonctions essentielles sont gratuites. Certains services (certifications, boutique, campagnes ads) sont payants en crédits ou en euros via Stripe.
  </Accordion>

  <Accordion title="Puis-je supprimer mon compte ?">
    Oui, via Paramètres → Confidentialité → « Supprimer mon compte ». Délai de rétractation de 30 jours pendant lequel vous pouvez annuler. Passé ce délai, suppression définitive (entité `DeletionRequest`).
  </Accordion>

  <Accordion title="Puis-je récupérer mon @username après l'avoir changé ?">
    Oui pendant 30 jours : votre ancien username est stocké dans `DeletedUsername` et vous êtes prioritaire pour le récupérer.
  </Accordion>

  <Accordion title="Est-ce que mes données sont vendues ?">
    Non. eza ne vend aucune donnée personnelle. Les services tiers (Stripe, SendGrid, Cloudflare) sont utilisés uniquement pour la technique.
  </Accordion>
</AccordionGroup>
