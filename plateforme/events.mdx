eza organise des événements en ligne, hybrides ou en présentiel. Vous vous inscrivez, vous récupérez un billet avec un code unique, et vous pouvez vous faire rembourser en crédits si besoin.

## S'inscrire à un événement

Le prix est en crédits Eza, débités à l'inscription : pas de carte bancaire à sortir.

## Mon billet et le check-in

- Votre billet est disponible dans « Mes événements ».
- Il contient un code unique (ex : `EZA-AB12CD34`).
- Sur place, présentez le code à un organisateur pour le check-in.
- Les événements en ligne vous envoient un lien de connexion.

## Organiser un événement

Si vous avez le rôle d'organisateur :

- Créez l'événement avec ses infos et son prix en crédits.
- Suivez la liste des inscrits et les check-ins.
- Validez les entrées en scannant les billets.
- Consultez les statistiques (inscrits, revenus).

## Synchronisation Outlook

Les rendez-vous liés à un événement peuvent être synchronisés avec Outlook (connecteur OAuth). Les modifications sont propagées via webhooks.
