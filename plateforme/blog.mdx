## Anatomie d'un article

| Champ | Contenu |
| --- | --- |
| Titre | Titre principal |
| Slug | URL propre |
| Extrait | Résumé pour la liste |
| Contenu | HTML/Markdown enrichi |
| Couverture | Image de mise en avant |
| Catégorie | Une parmi 5 |
| Tags | Mots-clés |
| Auteur | Snapshot profil |
| Publié | Statut visible/brouillon |
| Vues | Compteur automatique |
