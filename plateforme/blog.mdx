## L'entité `BlogPost`

| Champ | Type | Description |
| --- | --- | --- |
| `title` | string | Titre principal |
| `slug` | string | URL unique lisible |
| `excerpt` | string | Résumé (SEO \+ liste) |
| `content` | text | Corps de l'article (Markdown/HTML) |
| `cover_url` | string | Image de couverture |
| `category` | enum | actualite, conseil, technique, projet, formation |
| `tags` | array | Mots-clés indexés |
| `author_id` | string | Auteur |
| `author_name` | string | Snapshot nom auteur |
| `author_avatar` | string | Snapshot avatar |
| `is_published` | boolean | Publié ou brouillon |
| `published_at` | datetime | Date de publication |
| `views_count` | number | Compteur automatique |
| `read_time` | number | Minutes calculées |
| `meta_title` | string | SEO override |
| `meta_description` | string | SEO override |

## SEO natif

Chaque article génère :

- Balise `<title>` = `meta_title` ou `title`
- Meta description = `meta_description` ou `excerpt`
- Open Graph : `og:title`, `og:image` (cover), `og:type: article`
- Twitter Card : summary\_large\_image
- Structured data JSON-LD : `Article` schema
- URL canonique : `/blog/{slug}`
- Sitemap XML mis à jour automatiquement

## Fonction `blogPreview`

Une fonction backend `blogPreview` génère un aperçu Open Graph optimisé pour partage sur réseaux sociaux, avec image de couverture recadrée en 1200×630.

## FAQ Blog

<AccordionGroup>
  <Accordion title="Puis-je programmer une publication ?">
    Oui via `published_at` dans le futur. Une tâche cron `publishScheduledPosts` la rend visible à l'heure prévue.
  </Accordion>

  <Accordion title="Comment gérer les images ?">
    Upload direct dans l'éditeur, stockage sur CDN, compression WebP automatique. Poids max 5 MB par image.
  </Accordion>

  <Accordion title="Puis-je collaborer à plusieurs sur un article ?">
    Oui via le rôle `collaborateur_interne` ou `directeur` : édition partagée, historique des modifications.
  </Accordion>
</AccordionGroup>
