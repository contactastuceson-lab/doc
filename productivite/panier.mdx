## L'entité `Cart`

| Champ | Description |
| --- | --- |
| `user_id` | Propriétaire du panier |
| `items` | Tableau `{type, ref_id, credits, quantity}` |
| `total_credits` | Somme calculée |
| `status` | `active`, `checked_out`, `abandoned` |
| `updated_at` | Auto-save toutes les 30s |
