## Deux onglets

| Onglet | Contenu |
| --- | --- |
| **Signets** | Posts sauvegardés via l'icône signet (entité `Bookmark`) |
| **Brouillons** | Vos posts `is_draft: true`, non publiés |

## L'entité `Bookmark`

| Champ | Description |
| --- | --- |
| `user_id` | Propriétaire du signet |
| `post_id` | Post sauvegardé |
| `created_date` | Date de sauvegarde |

## Cycle d'un brouillon

<Note>
  **Perk `scheduled_posts_until`.** La publication programmée est un avantage boutique. Vérifiez que votre `perks.scheduled_posts_until` est actif.
</Note>
