## Comment ça fonctionne

La recherche est **instantanée côté client** pour les profils et hashtags, et parcourt les 100 derniers posts pour le contenu.

## Recherche par tag

URL directe : `/?tag=monTag`

<Note>
  **Sample profiles.** La recherche inclut les profils démo (`SampleProfile`) marqués `is_sample: true`. Utile pour explorer eza avant même de suivre quelqu'un.
</Note>

## Fonctions backend impliquées

| Fonction | Rôle |
| --- | --- |
| `getPublicUsers` | Récupère tous les profils publics |
| `getSampleProfiles` | Profils démo pour la découverte |
| `extractHashtags` | Extraction des tags depuis le contenu |
