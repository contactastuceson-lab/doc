## L'entité `UserList`

| Champ | Description |
| --- | --- |
| `owner_id` | Propriétaire de la liste |
| `name` | Nom de la liste |
| `description` | Description libre |
| `member_ids` | Tableau des IDs utilisateurs |
| `is_public` | Visible par tous ou privée |
| `cover_url` | Image optionnelle |

## Créer une liste

<Tip>
  **Pratique pour se concentrer.** Créez une liste "Priorités" avec vos 20 comptes favoris. Vous évitez le bruit du fil principal.
</Tip>
