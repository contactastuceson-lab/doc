## Bienvenue sur eza

**eza** est une plateforme communautaire tout-en-un : réseau social, forum, messagerie, portfolio, blog, événements, communautés, Spaces audio, stories, économie de crédits, certifications et support IA. Un seul compte, une seule identité, une seule app installable en PWA.

## Stack technique

<CardGroup cols={3}>
  <Card title="Frontend" icon="code">
    React 18 \+ Vite, Tailwind, Framer Motion, react-quill, Leaflet, recharts.
  </Card>

  <Card title="Backend" icon="server">
    Base44 BaaS, 63 entités, 126 fonctions serverless, RLS strictes.
  </Card>

  <Card title="Paiements" icon="credit-card">
    Stripe (checkout, portail, webhooks), tokens crédits, dons libres.
  </Card>

  <Card title="Notifications" icon="bell">
    VAPID Web Push, Firebase FCM, emails transactionnels.
  </Card>

  <Card title="Real-time" icon="zap">
    LiveKit pour Spaces audio/vidéo, WebSocket pour messagerie.
  </Card>

  <Card title="IA" icon="sparkles">
    Nexus (support agentique), analyse toits, refine message.
  </Card>
</CardGroup>

## Points forts

<Columns cols={2}>
  <Card title="🔐 RGPD natif" icon="shield-check">

  </Card>

  <Card title="🌍 Multi-langue" icon="languages">
