La messagerie eza permet des conversations privées 1-à-1 en temps réel avec un système de demandes de contact pour éviter le spam.

## Comment ça marche

Une conversation est identifiée par les emails des deux participants triés alphabétiquement. Chaque message contient :

- `sender_email`, `recipient_email`, `content`.
- Statut lu / non lu (`is_read`).
- Type spécial possible : demande (`is_request`), officiel (`is_official`), avertissement (`is_warning`).

## Le système de demandes

Le premier message envoyé à quelqu'un est une **demande de contact**. La conversation reste isolée dans le panneau des demandes tant qu'elle n'est pas acceptée.

</Steps>

<Tip>
  **Anti-spam natif.** Tant qu'une demande n'est pas acceptée, la conversation reste isolée. Votre boîte principale est protégée du spam.
</Tip>

## Messages officiels et avertissements

L'équipe eza peut envoyer trois types de messages spéciaux :

| Type | Affichage |
| --- | --- |
| Officiel (`is_official`) | Badge officiel, style dédié. |
| Avertissement (`is_warning`) | Couleur orange, mise en évidence. |
| Note admin (`is_admin_note`) | Non visible côté utilisateur. |

## Temps réel

Les messages utilisent les subscriptions temps réel : les nouveaux messages arrivent instantanément sans recharger la page, avec statut en ligne, auto-scroll et marquage automatique en lu.

## Modération des conversations

Chaque conversation peut être modérée via un contrôle :

- **Verrouillage bilatéral** : plus personne ne peut écrire dans la conversation.
- **Verrouillage unilatéral** : vous êtes verrouillé sur cette conversation.
- **Blocage** : blocage unidirectionnel entre les deux participants.
- Motif de modération conservé.

## Raffinement IA du message

Dans le composer, vous pouvez demander à l'IA de reformuler votre message (plus poli, plus clair, plus court) avant de l'envoyer. Vous prévisualisez le résultat, vous seul décidez d'envoyer.

<Note>
  **Vous restez maître.** Le raffinement est optionnel. L'IA vous aide à formuler, elle n'envoie jamais à votre place.
</Note>
