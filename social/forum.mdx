## Répondre et marquer une solution

- Ouvrez la discussion et descendez jusqu'à « Votre réponse ».
- Rédigez en Markdown (titres, gras, listes, citations, code).
- Aimez les réponses utiles (icône cœur).
- L'auteur du sujet peut marquer la meilleure réponse comme « solution » : elle devient verte et bien visible en tête.

## Filtrer et rechercher

- **Recherche** : texte libre dans tous les sujets.
- **Catégorie** : 7 options \+ « Toutes ».
- **Tri** : Récents / Populaires / Plus de réponses / Sans réponse.
- **Réinitialiser** : bouton pour effacer les filtres.

## Discussions mises en avant

| Badge | Signification |
| --- | --- |
| Épinglé | Sujet important, apparaît en premier. |
| Fermé | Plus de nouvelles réponses possibles. |
| Solution | Une réponse résout la discussion (post vert). |
| Officiel | Sujet publié par l'équipe eza. |
| Annonce | Annonce mise en avant avec bandeau. |

## Rendu et liens externes

- Rendu Markdown style Discord (titres, gras, italique, listes, citations, blocs de code).
- Les liens externes déclenchent une modale d'aperçu qui montre la destination avant redirection : protection anti-phishing.

## Modèle de forum

Le forum utilise l'entité `Discussion` (avec `DiscussionReply` pour les réponses). Un modèle alternatif `ForumTopic` / `ForumPost` existe : l'auteur reste persistant même après suppression de compte.
